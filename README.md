# Computational_Intelligence
A repository for projects implementing computational intelligence methods.

## Algorytm_Monte_Carlo
seeks to approximate \pi and visualizes the results for different number of random points.

## Algorytm_genetyczny_travelling_salesman
solves the travelling salesman problem utilising a genetic algorithm. This projects allows the user to modify parameters such as population size, number of cities, crossover and mutation rates and method of selection. Project provides both static visualizations of achieved best solution and animated visualizations of the algorithm in action.
